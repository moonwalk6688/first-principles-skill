# First Principles Skill

一套可直接使用的 AI skill 工具包——把李善友《第一性原理》中的核心认知与创新方法拆成了 10 个可单独触发、也可组合调用的判断模块。

这不是一本书的摘要页。书是这些 skill 的来源，不是首页主角。

## 这套 skills 能解决什么问题

- 面对复杂问题时，只会沿用行业常识，找不到更底层的起点
- 想做创新，但总是在旧系统里做局部优化，而不是打破边界
- 团队战略卡住了，却说不清真正限制组织的隐含假设是什么
- 看到市场共识很强，不确定该跟随还是反向思考
- 想建立一套可重复调用的认知框架，而不是靠灵感和口号

## 蒸馏了什么

从《第一性原理》中提取了 10 个经过三重验证的 skill，覆盖三个维度：

- **认知工具**：`implicit-assumption`（隐含假设识别）、`logic-triple-check`（逻辑三洽检验）、`critical-thinking`（批判性思维）
- **创新方法**：`axiomatic-thinking`（公理化思维）、`boundary-innovation`（破界创新）、`reductionism-deconstruction`（还原论拆解）
- **组织与决策**：`organizational-refresh`（组织刷新）、`founder-cognitive-boundary`（创始人认知边界）、`contrarian-decision`（反共识决策）、`multi-mental-models`（多元思维模型）

## 效果示例

### 示例 1：行业都这么做，我为什么还要重想一遍？

**用户问题**

"我们行业一直都是这样定价、这样做增长的，我要不要照着做？"

**skill 如何判断**

- 先触发 `implicit-assumption`，识别这个行业惯例背后的默认前提
- 再触发 `axiomatic-thinking`，回到更底层的公理或约束条件
- 如果需要真正改写玩法，再接 `boundary-innovation`

**最终回答示例**

> 不要先问“别人是不是都这么做”，先问“这个做法成立的前提是什么”。如果这个前提已经变了，比如用户注意力结构变了、分发方式变了、成本结构变了，那你延续的就不是经验，而是过期假设。先把假设拆出来，再判断哪些还能成立，哪些已经该被打破。

### 示例 2：组织为什么越做越重？

**用户问题**

"团队越来越大，但决策越来越慢，我感觉不是执行问题，是哪里卡住了。"

**skill 如何判断**

- 先触发 `founder-cognitive-boundary`，诊断组织边界是不是被创始人的旧认知锁住
- 再用 `organizational-refresh` 重看使命、文化、战略是否还同频
- 必要时补 `critical-thinking`，拆掉内部已经默认正确的信念

**最终回答示例**

> 很多组织不是被外部打败，而是被自己默认成立的前提困住了。你现在要找的不是“谁执行不到位”，而是“团队今天仍在服从哪一条早期假设”。如果那条假设已经过期，流程越多，只会把旧系统维护得更牢。

## 这些 skill 是怎么生成出来的

这套 skill 使用 **cangjie-skill** 的 RIA-TV++ 流水线生成，整个流程分六个阶段：

1. **整书理解（Adler 分析）**——对全书做结构、解释、批判、应用四步拆解，产出 `BOOK_OVERVIEW.md`
2. **并行提取**——从原文中并行提取框架、原则、案例、反例、术语候选
3. **三重验证筛选**——通过跨域、预测力、独特性三项检验
4. **RIA++ 构造**——把通过的单元写成可调用 skill
5. **Zettelkasten 链接**——生成 `INDEX.md`，建立 skill 之间的依赖与组合关系
6. **压力测试**——为每个 skill 设计 `test-prompts.json`，验证触发与边界

每个 `SKILL.md` 都是这个流程的真实产出，保留了 `candidates/` 和 `rejected/` 作为审计轨迹。
