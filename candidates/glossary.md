# 候选术语 (Glossary)

---

## g01: 第一性原理

```yaml
id: g01
title: 第一性原理
type: term
source_chapter: 第一章
source_quote: |
  "在每一系统的探索中，存在第一原理，它是一个最基本的命题或假设，不能被省略或删除，也不能被违反。"
summary: |
  任何理性系统的根基性命题/基石假设/元起点。关键特性：①在系统之外、之前（不是中心思想）②是直接给定的、能自确定的元前提（单向性法则）③有层级之分（大系统的中心思想可作为子系统的第一性原理）④一个系统可能有2-3个第一性原理（复数词 First Principles）。公式：第一性原理 + 演绎法 = 理性系统。
tags: [core-concept, first-principles, philosophy]
```

## g02: 隐含假设

```yaml
id: g02
title: 隐含假设
type: term
source_chapter: 第一章+第三章
source_quote: |
  "所谓隐含假设，就是推论在逻辑层面的大前提。在固定的时空中，忽略已经经过验证的前提去推导结果，在某种程度上来说是行之有效的。"
summary: |
  推论中被默认接受、不被质疑的前提条件。之所以叫"隐含"，是因为当人们长期在一个系统中生活工作时，会忘记系统下面有基石假设。归纳法的隐含假设是"连续性假设"（未来和过去一样），演绎法的隐含假设是"前提的正确性"。最常见的隐含假设是群体信念。破界创新的第一步就是发现隐含假设。
tags: [core-concept, implicit-assumption, premise]
```

## g03: 连续性假设

```yaml
id: g03
title: 连续性假设
type: term
source_chapter: 第一章
source_quote: |
  "连续性假设不是一个逻辑推理的结果，而是一个非逻辑的武断，它是一个默认正确的隐含假设，而不是必然正确的知识。"
summary: |
  归纳法得以成立的前提性假设——"未来和过去一样"。它是归纳法无法自我证明的悖论：我们用归纳法证明连续性假设，而归纳法本身依赖连续性假设。这是无限循环。所以连续性假设不是真理，而是"默认正确的武断"。一旦越过时空边界（非连续性节点），基于此假设的所有知识立即失效。
tags: [core-concept, continuity-assumption, induction]
```

## g04: 破界创新

```yaml
id: g04
title: 破界创新
type: term
source_chapter: 第三章
source_quote: |
  "破界创新是一种笛卡儿式的转向，所谓的破界，不是破外在现实的边界，而是破内在认知的边界。"
summary: |
  区别于在外部事物上的创新（组合创新、单点破局等），破界创新是通过打破内在认知边界引起外在现实变化，是"由内而外"的创新。它是混沌大学创新模型之王，也是本书最核心的方法论。不是在内容上做功，而是在结构上做功——不解决原有问题，而是让原有问题变得无关紧要。
tags: [core-concept, innovation, boundary-breaking]
```

## g05: 第一创新

```yaml
id: g05
title: 第一创新
type: term
source_chapter: 第五章
source_quote: |
  "公理化思维在创新中的应用，是从一个抽象的第一性原理出发，用逻辑思维将其拆解，进而推导出这个系统的基本原理，打破原有认知，寻找并建立新系统的过程。"
summary: |
  与破界创新互补的概念。破界创新关键词是"破"（打破旧系统），第一创新关键词是"立"（从第一性原理正向构建新系统）。破界创新从具象到抽象（识别隐含假设最难），第一创新从抽象到具象（找到第一性原理后推导）。马斯克是第一创新的典型代表：基于物理学的还原论，在多个领域构建全新系统。
tags: [core-concept, innovation, first-innovation]
```

## g06: 求存不求真

```yaml
id: g06
title: 求存不求真
type: term
source_chapter: 第一章
source_quote: |
  "从本质上讲，知识在一定时空边界内帮助我们得以求存，但它并不能帮助我们得到这个宇宙、这个世界的真相是什么。"
summary: |
  人类认知系统的根本设计原则。人类进化出用最小认知成本获取生存所需信息的机制，代价是永远无法认知世界的真相。这是"最小作用力原理"在认知领域的体现。归纳法不能得到真理但能帮我们生存，感官系统简化并扭曲外物但足够维护生存。所以所有知识都是"暂时正确的生存工具"而非"永恒真理"。
tags: [core-concept, epistemology, survival]
```

## g07: 逻辑三洽

```yaml
id: g07
title: 逻辑三洽
type: term
source_chapter: 第八章
source_quote: |
  "信念'正确'的判断标准是'逻辑三洽'，即自洽、他洽和续洽。"
summary: |
  判断信念是否"暂时正确"的三重标准。自洽：逻辑体系内部自圆其说且与相关事实相互证明。他洽：与周边逻辑系统及更深层次系统保持一致（如任何物理学理论必须符合熵增定律）。续洽：时代/场景变化后逻辑依然成立。任一不满足即需更新信念。这是代替"客观事实"判断真理的实用标准。
tags: [core-concept, logic, verification]
```

## g08: 从众效应

```yaml
id: g08
title: 从众效应
type: term
source_chapter: 第七章
source_quote: |
  "从众效应是指个体受到他人的影响，会怀疑并改变自己的观点，与他人保持一致以寻求安心。"
summary: |
  人类内置的认知偏见，从狩猎时代就刻入基因（不合群=死亡）。在组织层面表现为群体信念。其危险在于：①身处群体中看不出群体犯错（结构性缺陷）②即使看出来也不敢说 ③即使说了也没用。是最重要的隐含假设之一。破解需要批判性思维：普遍怀疑+不可知论+反共识。
tags: [core-concept, bandwagon-effect, groupthink]
```

## g09: 主体性认同

```yaml
id: g09
title: 主体性认同
type: term
source_chapter: 第八章
source_quote: |
  "'我'更像是一种主体性认同，就像在网络环境中，每个人的身份ID一样。"
summary: |
  "我"不是一个逻辑实体，必须依附于某个主体才能证实自身存在。结构为"我的××"——我的名字、我的工作、我的观点。这导致人类把"我的思想"等同于"我"，否定思想=否定存在。所以99%的争吵不是为了捍卫道理，而是为了捍卫"我"的存在性。打破主体性认同需要可证伪性态度：承认"我错了"。
tags: [core-concept, ego, identity]
```

## g10: 万物至理

```yaml
id: g10
title: 万物至理
type: term
source_chapter: 第六章
source_quote: |
  "如果你把整个宇宙当作一个系统，那么这个系统也有它根基的第一性原理，科学家把它称为'万物至理'。"
summary: |
  理论物理学家追求的终极目标——一个极简方程统一所有物理学理论。牛顿的F=ma统一了天体和地上运动，麦克斯韦方程组统一了电力磁力和光，爱因斯坦的相对论进一步统一了时空和质能，但量子力学与相对论至今未统一。万物至理是第一性原理在科学领域的极致表现。
tags: [core-concept, physics, theory-of-everything]
```
