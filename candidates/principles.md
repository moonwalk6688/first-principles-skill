# 候选原则 (Principles)

## p01: 逻辑三洽检验

```yaml
id: p01
title: 逻辑三洽检验
type: principle
source_chapter: 第八章
source_quote: |
  "信念'正确'的判断标准是'逻辑三洽'，即自洽、他洽和续洽。"
summary: |
  判断一个信念是否"暂时正确"的三重逻辑标准：①自洽——信念的逻辑体系内部可以自圆其说，且与相关事实相互证明；②他洽——信念所在的逻辑系统与周边相关系统及更深层次系统保持一致（如物理学理论必须符合熵增定律）；③续洽——当时代和场景变化、新信息出现后，原有信念的逻辑体系依然成立。任一不满足即意味着信念需要更新。
tags: [logic, verification, belief-system]
```

## p02: 归纳法只能证伪不能证明

```yaml
id: p02
title: 归纳法只能证伪不能证明
type: principle
source_chapter: 第一章
source_quote: |
  "归纳法只能证伪，却不能证明。科学理论和人类所掌握的一切知识都是推测和假想。"
summary: |
  归纳法的结论永远只是"等待被推翻的假说"。无论前提多么正确、实验验证多么充分，归纳出的规律不能保证一定为真。波普尔的可证伪性原则：有可能被证明是错误的学问才是科学。这意味着所有基于经验的知识都有边界，一旦跨越边界（非连续性节点）就会失效。
tags: [induction, falsifiability, epistemology]
```

## p03: 求存不求真

```yaml
id: p03
title: 求存不求真
type: principle
source_chapter: 第一章
source_quote: |
  "知识在一定时空边界内帮助我们得以求存，但它并不能帮助我们得到这个宇宙、这个世界的真相是什么。"
summary: |
  人类的认知系统不是为了追求真理而设计的，而是为了维护生存而设计的。我们用较小的认知成本获取维护生存所需的信息量，代价是永远无法认知世界的真相。感官系统会简化并扭曲外物（如将光的波长扭曲为"颜色"），这些扭曲在生存层面足够用，但在认知层面是失真的。所以不应追求"绝对正确"，而应追求"暂时有用的生存工具"。
tags: [epistemology, cognition, survival]
```

## p04: 破界创新不在内容上做功，在结构上做功

```yaml
id: p04
title: 在结构上做功而非内容上做功
type: principle
source_chapter: 第三章
source_quote: |
  "破界创新的思维方式不是在内容上做功，而是在结构上做功，是在看不到的地方做功。"
summary: |
  大多数创新努力集中在外部事物的内容层面（改进功能、优化流程），但真正的颠覆式创新是在结构层面——打破内在认知边界引起外在现实变化。福特没有解决马车的问题而是让马车问题无关紧要，乔布斯没有解决功能手机的问题而是让功能手机无关紧要。与其在系统内解决问题，不如跳出系统重新定义问题。
tags: [innovation, structure, problem-redefinition]
```

## p05: 可证伪性态度

```yaml
id: p05
title: 可证伪性态度
type: principle
source_chapter: 第八章
source_quote: |
  "能够认识到并承认自己错了，是证明一个科学家仍旧还是科学家的标志。"
summary: |
  可证伪性不只是科学定义，更是一种思维态度：对自己的信念始终保持"它可能是错的"的开放心态。波普尔认为真正的科学理论必须具备被证伪的可能性。在商业中，能承认"我错了"是创新者的标志；不能承认错误的领导者会导致"承诺升级效应"——为了维护面子继续追加投入，最终成本超过解决问题所需。
tags: [falsifiability, intellectual-honesty, growth]
```

## p06: 企业最大的成本是领导者的面子和尊严

```yaml
id: p06
title: 领导者面子是最大的组织成本
type: principle
source_chapter: 第八章
source_quote: |
  "在一个企业中，经营最大的成本不是试错，而是领导者的'尊严和面子'。"
summary: |
  当领导者认为自己不能犯错时，组织会出现"承诺升级效应"：发现错误后不但不停下，反而继续追加投入以证明自己是对的。保护领导者面子的成本最终会超过解决问题的成本。巴菲特87岁时公开承认投资IBM错了、错过亚马逊是因为太蠢——这种可证伪态度才是创新者的标志。
tags: [leadership, ego, organizational-cost]
```

## p07: 创始人的认知边界是企业发展的真正边界

```yaml
id: p07
title: 创始人认知边界=企业发展边界
type: principle
source_chapter: 第四章
source_quote: |
  "创始人/管理者的认知边界是一家企业发展的真正边界。微软从来没有被任何竞争对手打败，而是被它自己内在的隐含假设禁锢。"
summary: |
  企业的边界不是由市场或竞争对手决定的，而是由领导者的认知边界决定的。微软的隐含假设是"Windows就是一切"，这既是它的力量来源也是禁锢。鲍尔默时代营收增长4倍、利润增长10倍，但市值反降一半——因为成于第一曲线、失于第二曲线。只有刷新创始人的认知边界（使命/文化），才能刷新企业的战略边界。
tags: [leadership, cognitive-boundary, business]
```

## p08: 反共识：大多数人的共识一定是愚蠢的

```yaml
id: p08
title: 反共识原则
type: principle
source_chapter: 第八章
source_quote: |
  "大多数人的共识一定是愚蠢的。但凡常识的东西，都是行将抛弃的谬误。"
summary: |
  在商业和创新中，共识通常是错误的。达利欧："要想在投资中获得成功，你必须成为一个独立的思考者，因为共识通常都是错误的。"贝索斯："如果你要创新，你必须愿意长时间被误解。"蒂尔："大多数人相信X，但事实却是X的对立面。"这不是为了反对而反对，而是通过批判性思维和逻辑分析发现共识中的隐含假设错误。
tags: [contrarian, innovation, independent-thinking]
```

## p09: 成长型思维 vs 固化型思维

```yaml
id: p09
title: 成长型思维切换
type: principle
source_chapter: 第四章
source_quote: |
  "固化型思维的公司总在逃避风险，却又期待创新的出现。而成长型思维则会把关注点从到底做错了什么，转变到我们从中学到了什么。"
summary: |
  固化型思维认为能力是天生的、不变的，关注结果（证明自己是屋子里最聪明的人）；成长型思维认为能力可以通过努力提高，关注过程（从经历中学到什么）。纳德拉用这个切换刷新了微软文化：从各部门互相打架、封闭排他，变为开放合作、拥抱竞争对手平台。关键区别：固化思维看结果，成长思维看过程。
tags: [mindset, growth, culture-change]
```
