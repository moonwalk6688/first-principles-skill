## ce01: 经验主义陷阱——用归纳法指导非连续性时代

```yaml
id: ce01
title: 经验主义陷阱
type: counter-example
source_chapter: 第一章
source_quote: |
  "当企业的发展跨入新阶段或者行业市场发生了质的变化时，用原来归纳法思维总结出来的规律指导未来，不但毫无益处，反而有害。"
summary: |
  在连续性时期，归纳法（经验驱动）是最有效的管理思维。但一旦跨越非连续性节点（第一曲线→第二曲线），用原有经验指导未来不但无效反而有害。在第一曲线中经验丰富的员工，在第二曲线往往表现拙劣，因为他们被连续性假设裹挟，无法摆脱思维惯性。
tags: [failure-pattern, induction, non-continuity]
```

## ce02: DEC被自己的成功禁锢

```yaml
id: ce02
title: DEC被成功禁锢
type: counter-example
source_chapter: 第三章
source_quote: |
  "屠龙的少年最终往往会变成恶龙。当年的创新勇者DEC，在面对小型商用机转向个人计算机的历史浪潮时，令人遗憾地与个人计算机兴起的大时代擦肩而过。"
summary: |
  DEC靠打破IBM的隐含假设（计算机只用于大企业）成功，建立了"小公司也需要计算机"的新基石假设。但当个人计算机浪潮来临时，DEC自己被"计算机只能用于商业机构"的新隐含假设禁锢，创始人说"没有理由每个家庭都有一台计算机"。IBM破界创新的屠龙少年变成了新恶龙，被自己的第一曲线黑洞束缚。
tags: [DEC, failure, success-trap, implicit-assumption]
```

## ce03: 从众效应——最危险的隐含假设

```yaml
id: ce03
title: 从众效应的陷阱
type: counter-example
source_chapter: 第七章
source_quote: |
  "身处群体之中，即使群体信念错了，原则上我们是不可能看出群体在犯错，这就是所谓的真理的结构性缺陷。"
summary: |
  人类内置的从众心理是最难觉察的隐含假设。牛顿在"南海泡沫"中亏掉10-20年薪水；阿希实验中33%的人选择与群体一致的错误答案；斯坦福监狱实验中正常人在群体角色中迅速丧失个体意识。从众效应之所以危险，是因为它让人"看不出群体在犯错"，而"众人皆醉我独醒"的状态需要对抗极大的孤独感和定力。
tags: [bandwagon-effect, groupthink, cognitive-bias]
```

## ce04: "我执"——将思想等同于自我

```yaml
id: ce04
title: 我执陷阱
type: counter-example
source_chapter: 第八章
source_quote: |
  "为了证明'我是对的'，必须证明'你是错的'。99%的争吵其实都不是为了捍卫'我的思想'，而是一种出于本能的对自身存在性的防卫。"
summary: |
  "我"不是一个逻辑实体，必须依附于主体才能证实存在。这导致人类把"我的思想"等同于"我"——否定我的思想=否定我的存在。结果：①不能承认错误（因为承认错误=否定自己）②争论从道理之争升级为尊严之争③领导者面子成为组织最大成本（承诺升级效应）。
tags: [ego, identity, self-deception]
```

## ce05: 群体信念的自证循环

```yaml
id: ce05
title: 群体信念自证循环
type: counter-example
source_chapter: 第七章+第八章
source_quote: |
  "我们用来证明对象的证据，恰恰是我们要证明的对象本身。这种自证其明的推导，显然是一种无法完成的循环论证。"
summary: |
  真理连贯论的根本漏洞：用群体信念判断信念是否正确，但群体信念本身是否正确又由谁来判断？答案是更高维度的群体信念——形成自证循环。再加上真理符合论也不成立（所有"客观事实"都经过主观信念的过滤），结果是人类根本没有能力确定客观世界的真相。群体信念的黑洞让人既看不出错误，也不敢说出错误。
tags: [circular-reasoning, group-belief, epistemology]
```

## ce06: 破界创新的最大难点是发现隐含假设

```yaml
id: ce06
title: 发现隐含假设极其困难
type: counter-example
source_chapter: 第三章
source_quote: |
  "破界创新的关键和难点在于发现和打破隐含假设。与禅修非常类似，当看到'隐含假设'时，我们就'开始'打破它了。"
summary: |
  第一性原理在系统之外，身在其中的人如同鱼在水中不知水。发现隐含假设需要哲学思维（跳出系统），但这极其困难：①你必须质疑那些"所有人都不质疑"的东西 ②最常见的隐含假设恰好是群体共识（行业常规）③当你发现某个东西是隐含假设时，打破它就已经开始了。所以乔布斯、马斯克能破界而大多数人不能。
tags: [difficulty, implicit-assumption, zen]
```

## ce07: 感官扭曲——你以为看到的不是真相

```yaml
id: ce07
title: 感官扭曲真相
type: counter-example
source_chapter: 第七章
source_quote: |
  "我们只能感受到我们主观感受到的东西，永远不能直接感受到所谓客观存在的客体。"
summary: |
  人类只有5条感官通道（80%视觉+18%听觉），可见光仅占全部光谱的十万分之一，颜色是大脑将光波长扭曲后的主观模型。如果眼睛是光谱仪，所需能量超过人体全部代谢产出的万分之一。所以人类感知系统不是为"求真"设计的，而是为"求存"设计的——用最小认知成本获取生存所需信息，代价是永远无法认知世界真相。
tags: [perception, sensory-distortion, epistemology]
```
