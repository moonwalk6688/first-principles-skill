## f01: 破界创新三部曲

```yaml
id: f01
title: 破界创新三部曲
type: framework
source_chapter: 第三章
source_quote: |
  "破界创新可以分成以下3个步骤：1.'破'隐含假设 2.'立'基石假设 3.'见'全新系统"
summary: |
  打破系统边界的创新方法论，分三步执行。第一步（最难）：识别并打破原有系统的隐含假设，即群体信念中不被质疑的默认前提。第二步：在打破旧假设后，重构一个层次更深、强度更大的新基石假设。第三步：在新基石假设上，通过演绎法推导出全新系统。这不是在内容上做功，而是在结构上做功——不是解决原有问题，而是让原有问题变得无关紧要。
tags: [innovation, boundary-breaking, mental-model]
```

## f02: 公理化思维框架

```yaml
id: f02
title: 公理化思维框架
type: framework
source_chapter: 第二章
source_quote: |
  "公理化思维就是人类在生活和工作中，以公理或第一性原理为根基，运用逻辑思维去推理，并建立其他理性思维体系的一种方式。"
summary: |
  从少数几条不证自明的公理（第一性原理）出发，通过演绎法的逻辑推导，构建出完整的理性系统。欧氏几何是范本：5个公设+5个公理+23个定义，推导出48条定理和467个命题。牛顿力学建立在惯性假设+引力假设之上，狭义相对论建立在相对性原理+光速不变之上。核心逻辑：公理是第一重要的，找到公理后推导只是勤奋问题。
tags: [axiomatic-thinking, logic, deduction]
```

## f03: 还原论拆解法（马斯克范式）

```yaml
id: f03
title: 还原论拆解法
type: framework
source_chapter: 第五章
source_quote: |

summary: |
  基于物理学还原论的创新方法：将复杂系统拆解到最基本要素（原子层面），然后以全新的方式重新组合，实现十倍好甚至百倍好的突破。马斯克用此方法拆解电池成本（从600美元/千瓦时降至82美元材料成本），拆解火箭成本（原材料仅占总成本2%），拆解隧道成本（实现百倍好的成本控制）。核心步骤：①要素拆解到最底层 ②发现成本/效率瓶颈的真实原因 ③以新方式重新组合。
tags: [reductionism, innovation, musk, cost-engineering]
```

## f06: 批判性思维框架

```yaml
id: f06
title: 批判性思维框架
type: framework
source_chapter: 第八章
source_quote: |
  "批判性思维是建立在普遍怀疑之上的不可知论。创新精神的第一特征是批判性思维，独立思考，普遍怀疑，反共识。"
summary: |
  打破认知边界的元方法论，分两个层次。第一层"我错了"：承认自己的信念可能是错的（可证伪性），将"我"与"我的思想"解绑。第二层"我们错了"：对群体信念保持普遍怀疑（不可知论），不被从众效应裹挟。核心工具：可证伪性态度（波普尔）+ 普遍怀疑（笛卡儿）+ 不可知论（苏格拉底/休谟/康德）→ 反共识行动。芒格的实践标准："如果哪一年你没有破坏至少一个你最爱的观念，那么这一年就算白过了。"
tags: [critical-thinking, skepticism, falsifiability, anti-consensus]
```

## f07: 隐含假设识别法

```yaml
id: f07
title: 隐含假设识别法
type: framework
source_chapter: 第一章+第三章
source_quote: |
  "推翻一个结论，不要从结论入手，而是要从它的隐含假设开始，如果根基的隐含假设不成立，结论自然不成立。"
summary: |
  任何理性系统都建立在隐含假设之上，而身处系统之内的人往往看不到这些假设。识别方法是：①追溯任何结论/决策的"大前提"是什么 ②追问这个大前提是否有证据支撑，还是"默认正确" ③检查这个大前提是否来自归纳法（如果是，则它只是连续性假设而非真理）。最常见的隐含假设类型：时间连续性（未来和过去一样）、空间一致性（此地规律适用彼地）、群体共识（大家都这么做所以是对的）。
tags: [implicit-assumption, cognitive-boundary, reasoning]
```

## f08: 迁移式学习法（马斯克学习法）

```yaml
id: f08
title: 迁移式学习法
type: framework
source_chapter: 第五章
source_quote: |
  "迁移式学习首先应将知识拆解为基本原理，把知识看作一棵语义树很重要。深入细节或枝叶前，保证你可以理解基本原理，也就是主干和大分支。"
summary: |
  马斯克的跨领域学习方法，区别于传统的"从普通知识到专业知识"的窄化学习路径。分两步：第一步将知识拆解为基本原理（语义树的主干和大分支），第二步在新领域中重构这些基本原理，然后在上面挂细节。核心洞察：当你在多个领域深挖到最基础的根源时，会发现它们本质上是同一件事。张一鸣也表达了类似观点："外界看字节跳动是App工厂，但它们是一个东西。"
tags: [learning, transfer-learning, musk, cross-domain]
```

## f09: 升维思考法

```yaml
id: f09
title: 升维思考法
type: framework
source_chapter: 第六章
source_quote: |
  "自然规律在高维空间更简单。升维不仅是一种简单的思维方式，还能够帮助我们有效地打破原有的认知边界。"
summary: |
  在问题的原有维度上只能呈现问题，只有换一个更高的维度才能解决问题。爱因斯坦的示范：在三维空间中时间与质量都是绝对的，但升到四维时空后，时间变成相对的，质量与能量统一为"质能"，引力被重新解释为时空弯曲而非力。商业应用：不要在现有竞争维度上改善（归纳法），而要找到更高的维度（第一性原理）重新定义问题。
tags: [dimensional-thinking, einstein, problem-solving]
```
